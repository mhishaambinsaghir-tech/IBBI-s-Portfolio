# 🎨 Ibtisam's Portfolio Website

> A modern, responsive portfolio website for Ibtisam — Content Creator, Storyteller & Digital Freelancer.

🌐 **[View Live Portfolio](https://mhishaambinsaghir-tech.github.io/IBBI-s-Portfolio/)**

---

## 🎯 About the Project

This project is a modern **frontend portfolio website** built from scratch using HTML, CSS, and vanilla JavaScript.

The website provides a professional digital presence for showcasing creative work, services, skills, testimonials, and contact information through an interactive single-page experience.

It is designed around a premium visual identity combining dark surfaces, gold accents, custom typography, animations, and responsive layouts.

---

## ✨ Features

* 🌓 **Dark / Light Theme** with persistent `localStorage` preferences
* 📱 **Responsive Design** for desktop, tablet, and mobile devices
* 🧭 **Interactive Navigation** with mobile menu and scroll-spy behavior
* 🎨 **Portfolio Filtering** by project category
* ✨ **Scroll Animations** powered by `IntersectionObserver`
* 📈 **Scroll Progress Indicator**
* 🖱️ **Smooth Scrolling** between sections
* 🌊 **Hero Parallax Effects**
* 💎 **Glassmorphism-Inspired UI**
* ⭐ **Client Testimonials**
* 🛠️ **Service Showcase**
* 📩 **Contact Section**
* 📱 **Floating WhatsApp Contact Button**

## ⚡ Interactive Functionality

The website uses vanilla JavaScript to implement:

### Navigation

* Mobile menu toggle
* Smooth section scrolling
* Active navigation highlighting
* Scroll-based navbar effects

### Theme System

The theme system:

1. Detects the user's system preference
2. Allows manual theme switching
3. Stores the selected preference using `localStorage`

### Scroll Effects

* Scroll progress tracking
* Hero parallax movement
* Scroll-spy navigation
* Intersection-based animations

### Portfolio Filtering

Portfolio items can be filtered dynamically by their assigned category without reloading the page.

## 🚀 Running Locally

No framework, package manager, or build process is required.

### Clone the Repository

```bash
git clone https://github.com/mhishaambinsaghir-tech/IBBI-s-Portfolio.git
cd IBBI-s-Portfolio
```

### Open the Website

Simply open:

```text
index.html
```

in a modern web browser.

For development, you can also use VS Code Live Server or another local static server.
